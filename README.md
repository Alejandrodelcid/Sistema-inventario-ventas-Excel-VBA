# Sistema de Gestión de Inventario y Ventas

Sistema desarrollado en Excel y VBA para gestionar operaciones de inventario, compras, ventas y empleados.

## Descripción

Este proyecto consiste en un sistema automatizado desarrollado en Excel mediante macros y programación en VBA.

El sistema permite registrar productos, controlar existencias, gestionar ingresos de mercadería, registrar ventas y administrar información de empleados.

El objetivo principal es centralizar estas operaciones y reducir el trabajo manual mediante automatizaciones dentro de Excel.

## Funcionalidades principales

- Creación de códigos únicos para productos.
- Registro de ingresos de mercadería.
- Control de stock y precios de venta.
- Historial de movimientos de inventario.
- Registro de ventas.
- Generación automática del número de transacción.
- Registro automático de la fecha de la operación.
- Creación de códigos únicos para empleados.
- Asignación y seguimiento de metas mensuales.
- Consulta del alcance de metas por mes y año.
- Validaciones de datos para evitar registros incorrectos.

## Tecnologías utilizadas

- Microsoft Excel
- VBA (Visual Basic for Applications)
- Tablas estructuradas de Excel
- Fórmulas y funciones de Excel
- Automatización mediante macros

## Desarrollo y capacidades técnicas

Durante el desarrollo del proyecto se aplicaron diferentes conceptos de Excel y programación en VBA para automatizar y controlar los procesos del sistema.

### Automatización con VBA

- Automatización del registro de compras y ventas.
- Generación automática de números de transacción.
- Generación de códigos únicos para productos y empleados.
- Inserción automática de registros en tablas.
- Actualización de información mediante macros.

### Validación y control de datos

- Validación de datos ingresados por el usuario.
- Control de campos obligatorios.
- Validación de valores numéricos y de texto.
- Detección de registros duplicados.
- Mensajes de alerta para prevenir registros incorrectos.

### Gestión de datos

- Uso de tablas estructuradas de Excel.
- Búsqueda y comparación de registros.
- Control de entradas y salidas de inventario.
- Seguimiento de existencias y precios.
- Registro histórico de operaciones.

### Lógica de programación

- Uso de variables y diferentes tipos de datos.
- Estructuras condicionales `If / Then / Else`.
- Bucles `For` y `For Each`.
- Uso de variables booleanas para controlar procesos.
- Manejo de errores y control del flujo de ejecución.

### Diseño y experiencia de usuario

- Menú principal para facilitar la navegación.
- Formularios de captura de información.
- Botones para ejecutar las diferentes funciones.
- Protección de hojas y control de las áreas editables.
- Diseño visual orientado a facilitar el uso del sistema.

## Estructura del sistema

El sistema se encuentra organizado en diferentes módulos de Excel, cada uno enfocado en una función específica:

- Gestión de productos y catálogo.
- Control y consulta de inventario.
- Registro de compras e ingreso de mercadería.
- Registro de ventas y movimientos de inventario.
- Gestión de empleados.
- Asignación y seguimiento de metas.
- Automatización de procesos mediante VBA.

## Retos y soluciones

Durante el desarrollo se presentaron diferentes retos relacionados con la automatización, validación y organización de la información.

### Validación de datos

Se implementaron validaciones mediante VBA para evitar registros incompletos, valores incorrectos y datos duplicados antes de almacenarlos en las tablas.

### Automatización de registros

Se desarrollaron macros para automatizar la inserción de información en tablas, generación de números de transacción y actualización de los registros.

### Control de duplicados

Se implementaron procesos de búsqueda y comparación de registros para detectar posibles duplicados antes de guardar la información.

### Manejo de errores

Se incorporaron controles para evitar errores durante la ejecución de las macros y proporcionar mensajes al usuario cuando la información ingresada no cumple con las condiciones requeridas.

## Resultados

El desarrollo del sistema permitió:

- Reducir el ingreso manual de información mediante automatizaciones.
- Mejorar el control de las existencias y movimientos de inventario.
- Reducir errores mediante validaciones automáticas.
- Centralizar la información de productos, compras, ventas y empleados.
- Facilitar la consulta de información mediante registros estructurados.
- Automatizar procesos repetitivos mediante macros desarrolladas en VBA.
